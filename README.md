# MYLINGO A1 Level Repository

Repository name: `mylingoE1A1`

This repository supplies the `a1/` level content to the
main MYLINGO application repository `mylingoE1`.

## Structure

    a1/
    ├── index.html
    ├── dashboard.html
    └── quizzes.json

The folder is intentionally named `a1` because the main
deployment workflow copies it into:

    mylingoE1/site/a1/

Do not rename the folder or add another `site/` wrapper unless
the main deployment workflow is changed accordingly.
